# 🤖 AI FAQ Chatbot - CodeAlpha Internship

## 📌 Project Overview
This is a FAQ Chatbot built using Python and NLP techniques as part of CodeAlpha AI Internship.

---

## 🚀 Features
- Chatbot interface using Streamlit
- NLP-based question matching
- TF-IDF + Cosine Similarity
- Confidence score for answers
- Handles unknown questions
- Chat history support

---

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn

---

## ⚙️ How to Run

### Install requirements
pip install -r requirements.txt

### Run project
streamlit run app.py
